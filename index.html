Eurostat Statistics API

Eurostat предоставя напълно безплатен REST API за достъп до всички публични данни. Не е нужна регистрация, API ключ или автентикация.

📍 Base URL

https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/{dataset}

📝 Примери

БВП на България за 2023:

https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/nama_10_gdp?geo=BG&time=2023&unit=CP_MEUR&na_item=B1GQ&lang=EN

Инфлация на няколко страни:

https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/prc_hicp_manr?geo=BG&geo=RO&geo=GR&coicop=CP00&lang=EN

📋 Основни параметри

Параметър Описание Пример
geo Код на страна (ISO 2) BG, DE, EU27_2020
time Година или период 2023, 2024Q1, 2024M06
lang Език на етикетите EN, DE, FR
unit Мерна единица CP_MEUR, PC_ACT, I21

🔗 Полезни връзки

  • Eurostat Data Browser - Официален интерфейс
  • Query Builder - Визуален конструктор на заявки
  • API Documentation - Пълна документация
  • Database - Списък с всички datasets

💻 JavaScript пример

// Извличане на БВП на България
const url = 'https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/nama_10_gdp?geo=BG&time=2023&unit=CP_MEUR&na_item=B1GQ';

const response = await fetch(url);
const data = await response.json();

console.log(data.label);  // Dataset name
console.log(data.value);  // Data values
